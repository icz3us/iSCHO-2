================================================================================
DATABASE SCHEMA
================================================================================

Table: ocr_results (AUTO-CREATED)
──────────────────────────────────

Fields:
  • id (INT, AUTO_INCREMENT, PRIMARY KEY)
  • user_id (INT, FOREIGN KEY → users.id)
  • document_type (VARCHAR 50) - Type: cor, indigency, voter, etc.
  • extracted_text (LONGTEXT) - The OCR extracted text
  • confidence (DECIMAL 3,2) - Confidence score (0.00-1.00)
  • language (VARCHAR 10) - Language detected (default: eng)
  • processing_time (INT) - Processing time in milliseconds
  • file_path (VARCHAR 500) - Path to original document
  • created_at (TIMESTAMP) - Record creation time
  • updated_at (TIMESTAMP) - Last update time

Indexes:
  • UNIQUE(user_id, document_type) - One record per document type per user
  • INDEX idx_user_id (user_id)
  • INDEX idx_document_type (document_type)
  • INDEX idx_created_at (created_at)

HOW TO USE THE OCR FEATURE
================================================================================

STEP-BY-STEP GUIDE:
───────────────────

1. Login as Admin/Superadmin
   └─ Go to http://localhost/ischo2/admindashboard.php

2. Navigate to Admin Dashboard
   └─ View all applicants or search for specific applicant

3. Open Applicant Document
   └─ Click on any document (COR, Voter ID, Indigency Certificate)

4. Click "Extract Text" Button
   └─ Purple button in document viewer modal

5. Start OCR Processing
   └─ Click "Extract Text with OCR" button
   └─ Wait for processing (typically 3-15 seconds)

6. Review Results
   └─ Check extracted text
   └─ Review quality metrics:
      • Confidence percentage
      • Quality score
      • Text length
      • Processing time
   └─ Check detected information (names, IDs, dates, etc.)

7. Accept or Retry
   └─ Accept & Save: Stores results to database ✅
   └─ Retry: Re-run extraction 🔄
   └─ Discard: Cancel operation ❌

================================================================================
API ENDPOINTS
================================================================================

All endpoints are at: ajax_ocr_handler.php

REQUEST METHODS: POST only

─────────────────────────────────────────────────────────────────────────────

ACTION: extract_text
Purpose: Extract and store OCR results
Required Fields:
  • action: "extract_text"
  • user_id: [applicant ID]
  • document_type: [cor|indigency|voter|profile_picture]
  • extracted_text: [extracted text content]
  • confidence: [0.0 to 1.0]
  • processing_time: [milliseconds]
Response: { success: bool, message: string, data?: object }

─────────────────────────────────────────────────────────────────────────────

ACTION: get_results
Purpose: Retrieve OCR results for specific document
Required Fields:
  • action: "get_results"
  • user_id: [applicant ID]
  • document_type: [document type]
Response: { success: bool, data?: {ocr_result_object} }

─────────────────────────────────────────────────────────────────────────────

ACTION: get_user_results
Purpose: Get all OCR results for a user
Required Fields:
  • action: "get_user_results"
  • user_id: [applicant ID]
Response: { success: bool, data?: [ocr_results_array] }

─────────────────────────────────────────────────────────────────────────────

ACTION: validate_document
Purpose: Validate extracted text quality
Required Fields:
  • action: "validate_document"
  • extracted_text: [text content]
  • document_type: [document type]
  • confidence: [0.0 to 1.0]
Response: { success: bool, data?: {validation_object} }

─────────────────────────────────────────────────────────────────────────────

ACTION: get_stats
Purpose: Get OCR system statistics
Required Fields:
  • action: "get_stats"
Response: {
  success: bool,
  data?: {
    total_processed: int,
    total_users: int,
    avg_confidence: float,
    avg_processing_time: int,
    last_processing_time: timestamp
  }
}

================================================================================
QUALITY SCORING ALGORITHM
================================================================================

The OCR feature uses a comprehensive quality scoring system (0-100 points):

Point Allocation:
  +20 points: Text length > 20 characters
  +20 points: Word count > 3
  +20 points: Contains letters (alphabetic characters)
  +15 points: Contains numbers (numeric characters)
  +25 points: Confidence score > 70%
  ─────────
  TOTAL: 100 points maximum

Validation Threshold: 50 points minimum
  ✅ Score ≥ 50: Valid extraction
  ⚠️ Score < 50: Low confidence (user can still accept)

Quality Levels:
  90-100: Excellent quality
  70-89:  Good quality
  50-69:  Acceptable quality
  < 50:   Low quality (but still usable)

PERFORMANCE & OPTIMIZATION
================================================================================

FIRST-TIME SETUP:
  • Tesseract.js downloads language models (~50MB)
  • Download time: 30-60 seconds (depends on internet speed)
  • ⚠️ This only happens ONCE - subsequent uses are much faster
  • Tip: Be patient during first use

TYPICAL PROCESSING TIMES:
  • Low-quality image: 15-20 seconds
  • Medium-quality image: 8-12 seconds
  • High-quality image: 3-8 seconds
  • Average: ~8 seconds

OPTIMIZATION TIPS:
  1. Use high-quality, clear document scans
  2. Ensure sufficient system RAM (minimum 2GB)
  3. Close unnecessary browser tabs
  4. Use modern browser for best performance
  5. Check internet connection is stable
  6. Avoid processing multiple documents simultaneously

BROWSER CACHE:
  • Tesseract.js models cached locally
  • Subsequent uses much faster
  • Clear browser cache only if necessary
  • Cache size: ~50MB (one-time)

TROUBLESHOOTING GUIDE
================================================================================

PROBLEM: "Failed to initialize Tesseract"
SOLUTION:
  ✓ Check browser compatibility (see Browser Compatibility section)
  ✓ Ensure JavaScript is enabled
  ✓ Check internet connection
  ✓ Try different browser
  ✓ Check browser console for errors (F12)
  ✓ Refresh page and try again

PROBLEM: OCR returns no text
SOLUTION:
  ✓ Try with higher quality image
  ✓ Ensure document is clear and readable
  ✓ Try different document format
  ✓ Retry extraction with "Retry" button
  ✓ Check if browser console shows errors

PROBLEM: Low quality score warning
SOLUTION:
  ✓ This is expected for poor quality images
  ✓ System is being cautious - you can still accept results
  ✓ Try with clearer image next time
  ✓ Manually correct extracted text if needed

PROBLEM: Processing takes too long (> 1 minute)
SOLUTION:
  ✓ First use downloads models (~50MB) - this is expected
  ✓ Check internet connection speed
  ✓ Check system resources (RAM usage)
  ✓ Close other browser tabs
  ✓ Try again - usually faster on subsequent attempts

PROBLEM: "Unauthorized" error
SOLUTION:
  ✓ Ensure logged in as Admin or Superadmin
  ✓ Check user role in database
  ✓ Try logging out and logging back in
  ✓ Check browser's session/cookies

PROBLEM: Results not saving to database
SOLUTION:
  ✓ Verify MySQL connection is working
  ✓ Check database has write permissions
  ✓ Verify ocr_results table exists (auto-created)
  ✓ Check browser console for AJAX errors
  ✓ Verify ajax_ocr_handler.php is accessible
